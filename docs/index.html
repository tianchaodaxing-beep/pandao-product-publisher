下载工具查看使用说明

支持 Coupang 韩国站、WooCommerce 独立站。需连接店铺和 WordPress 图片库；下载后在本机运行。

一次完成一批商品

  1. 准备商品文件夹或中文商品表格。
  2. 选择店铺，核对图片、售价、库存和规格。
  3. 执行上传、保存草稿或提交发布。
  4. 查看商品编号、平台状态和处理结果。

适合重复上架和维护

  • 按商品编码查找原商品，支持多规格。
  • 失败商品可续接，其他商品继续执行。
  • 自动处理图片副本，保留原始资料。
  • 运行时不额外消耗语言模型额度。

首版建议先保存一个商品草稿。Coupang 提交后，以平台审核状态为准。
